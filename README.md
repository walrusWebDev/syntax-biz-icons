# syntax-biz-icons
Custom icons for a WordPress FSE Parent Theme


Original prompt for stitch.withgoogle.com

Can you create a sprite sheet of icons with the following:
Custom Icon & Line Illustration List
These should be designed as 1px or 2px stroke-based line icons using `hex code` and accented with `hex code` tokens.
1. Core Service & Pillar Icons 
-Theme Architecture: A stylized wire frame box or nested brackets representing modular FSE blocks and theme.json layers.
-Plugin & API Logic: A plug connecting to a data bracket or a minimal webhook wave node.
-Staging & Deployment: A dual-node server sync arrow (representing local Docker pushing to a live staging sandbox).
-Analytics / Telemetry: A clean, minimal spark line graph or dashboard gauge dial.
-Scale / WooCommerce: A modular three-tier stacking block or performance speed lines.
-Cloud Infrastructure: A streamlined edge-network cloud node with minimal connection dashes.
-Computer Terminal: A classic >_ bracket prompt box.

2. Problem / Incident Log Icons
-White Screen of Death: A minimalist computer monitor displaying a broken warning triangle or a slashed PHP/code symbol.
-Silent Lead Form Drops: An envelope icon with a small dotted red routing arrow missing its target or hitting a dead-end block.
-Sluggish Mobile Experience: A mobile phone outline with a lagging hourglass or a heavy weight symbol.
-Agency Red Tape: A traditional ticketing tag or a clock trapped behind a bureaucratic gear barrier.

3. Trust & UI Micro-Illustrations
-Stylized Check marks: Sharp, geometric check icons with precise angles to replace the default material symbols.
-Engineer / Accountability: A minimal terminal avatar node or a clean drafting compass/ruler cross.
-Clock / SLA Response: A minimal circular clock face with a bold accent hand pointing to a fast interval.
-Diagnostics / Audit: A magnifying glass intersecting a code bracket or a health pulse line.
-Video Playback: A streamlined minimalist play button node inside a rounded bento container.
